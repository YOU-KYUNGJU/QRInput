# FITI UI 계약 문서

## 목적
코드가 의존하는 FITI UI 조건을 문서화한다.

## 필수 창
- 로그인 창 제목: `시험관리시스템 로그인`
- 메인 창 제목: `Fiti`
- QR 창 제목: `QR스캔`
- 로그인 확인 버튼 기본 컨트롤: `Button1`
- 협조요청 등 예기치 않은 모달 확인 버튼 기본 컨트롤: `Button1`

## 표준 운영 환경
- Windows: 운영 PC 표준 이미지 기준
- 배율: 100%
- DPI: 표준값 유지
- 단일 모니터 권장
- 원격 접속 시 해상도 변경 금지
- FITI 창 위치 및 크기 고정 운영 권장

## QR 창 계약
- 입력창이 존재해야 한다.
- 빨간 체크 박스 기준 좌표/색상은 config에서 관리한다.
- 저장 완료 전후 별도 팝업이 없을 수 있으므로 화면 상태 변화 또는 후속 판정 기준을 둔다.

## UI 변경 감지 항목
다음 중 하나라도 바뀌면 계약 문서를 갱신한다.
1. 창 제목
2. 버튼 위치
3. 체크 박스 위치
4. 저장 완료 후 화면 상태
5. 로그인 컨트롤 이름
6. 주요 텍스트 라벨

## 권장 구현
1. 가능한 경우 Control 기반 우선
2. 좌표/픽셀은 보조 수단
3. 모든 좌표/색상은 config 외부화
4. 대기는 `Sleep` 누적보다 `WaitForCondition` 사용
5. 로그인 제출 후 추가 키 입력은 기본 비활성화
6. 예기치 않은 FITI 모달은 `dialog_confirm_button` 컨트롤 우선으로 닫는다
7. 모달 확인 후 후속 키 입력은 기본 비활성화하고 필요 시 config로만 제어한다
